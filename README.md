# 🐾 PawsApp

Aplicación móvil para amantes de los perros enfocada en el cuidado diario, la gestión de perfiles de mascotas y la conexión con la comunidad local.

---

## Estructura del proyecto

- **[Diseño UI/UX (`figma/`)](./figma):** Identidad visual, pantallas principales y prototipo interactivo.
- **[Aplicación Android (`kotlin/`)](./kotlin):** Implementación nativa en Kotlin con Android Studio y APK de demostración.
